# 来源规范（source-policy）

## 分级

见 `data/source-registry.json`：一级（厂商公告、CISA KEV、NVD、CVE Program、官方项目公告）、
二级（安全厂商报告、研究者公开报告、会议演讲、修复 PR）、三级（媒体、社区、博客、社交平台）。

## 引用规则

- 已发布案例至少 2 条引用，其中至少 1 条一级来源。
- 关键事实（编号、时间线、影响版本、修复建议）必须有一级来源支撑。
- 二级来源用于技术背景补充，最好与一级来源交叉核实。
- 三级来源只做线索，不单独支撑高风险结论。
- 引用链接必须为 HTTPS；引用时保留来源原意，不转载受版权限制的全文。

## 日期规则

- 「首次披露」「厂商修复」「确认在野利用」「本站最后复核」四个日期分别标注，不得合并为「发布日期」。
- 在野利用的判断依据：CISA KEV、厂商通报或多个可信报告；三者都没有时写「未确认」。
