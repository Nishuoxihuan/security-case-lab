# 本地实验边界（local-lab-boundary）

公开站（`security-case-lab`）与私有实验笔记（`security-lab-notes`，不公开）的分界线：

## 公开站可以写

- 事件复盘：发生了什么、时间线、影响条件。
- 攻击模型与信任边界：攻击为何可能成立（抽象层）。
- 检测与排查：日志、资产、配置、身份侧的可观测证据。
- 修复、缓解与验证：补丁、配置变更、验收标准。

## 只留在私有实验笔记

- Docker / VM 靶场搭建过程与快照。
- 抓包数据、实验流量、调试记录。
- 工具的具体使用练习与个人观察笔记。
- 任何在自建环境中验证利用链的详细步骤。

## 铁律

- 实验仅限自建靶场、官方练习平台或有书面授权的环境。
- 不针对真实资产做扫描、枚举或利用验证。
- 不在公开站发布可直接武器化的 EXP、载荷、C2 配置或绕过检测的细节。
- 不收录未修复 0day 的可利用细节。
